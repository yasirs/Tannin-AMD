# Data Directory

This directory contains all data used and generated by the project, organized by source and type.

## Directory Structure

*   **`external/`**: Public datasets downloaded from repositories like GEO, Figshare, etc.
    *   **`geo/`**: Gene Expression Omnibus datasets. These can be acquired by searching their accession numbers on the [NCBI GEO website](https://www.ncbi.nlm.nih.gov/geo/).
        *   **`GSE135092/`**: AMD RNA-seq cohort (N=537). Accession: GSE135092.
        *   **`GSE29801/`**: AMD Microarray cohort (N=293). Accession: GSE29801.
        *   **`GSE99287/`**: AMD RPE ATAC-seq Atlas. Accession: GSE99287.
        *   **`GSE129964/`**: RPE Serum Starvation Timecourse. Accession: GSE129964.
    *   **`perturbseq/`**: Large-scale CRISPR screens (Replogle et al. 2022). Datasets can be acquired from [Figshare+](https://plus.figshare.com/articles/dataset/_Mapping_information-rich_genotype-phenotype_landscapes_with_genome-scale_Perturb-seq_Replogle_et_al_2022_processed_Perturb-seq_datasets/20029387) (DOI: 10.1016/j.cell.2022.05.013). Includes:
        *   K562 Genome-wide Perturb-seq (GWPS)
        *   K562 Essential-scale Perturb-seq
        *   RPE1 Essential-scale Perturb-seq
*   **`RPE_cells/`**: Internal RPE bulk RNA-seq data (H2O2/PRG4 perturbations).
*   **`RPE_DE_results.csv` / `RPE_TPMS.csv`**: Downstream DE and TPM processed files generated from the `RPE_cells` internal dataset.

## Data Management Policy

*   **Git:** Raw data files (fastq, bam, large csvs) are **ignored** by git to keep the repository light.
*   **Reproduction:** Use the scripts in `code/external-validation/` to re-download or re-process these datasets.
